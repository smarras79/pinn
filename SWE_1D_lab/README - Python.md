# SWE_1D
This is a Shallow Water Equations solver (in 1D), which employs the HLL approximate Riemann solver.

The code is based on the HLL solver, as presented in Toro, E.F. (2001) <em>Shock-Capturing Methods for Free-Surface Shallow Flows</em>. Great Britain: Wiley. Bed friction is included via a semi-implicit method. The bedslope term is incorporated using the method described by Valiani and Begnudelli (<em>J. Hydraul. Eng.</em>, 2006, 132(7): 652-665). 

For Python version of this Program:
A) Prerequisites:
1. In src folder; its required to have two files: SWE1D_HLLC.exe and working_directory.inp
    1.1 working_directory.inp should have the full path to runs folder.
2. In runs folder; its required to have below files:
    2.1 swe_test_cases.py
    2.2 view_results.py

B) How to run test cases
1. Run python file runs/swe_test_cases.py
    1.1 Change swe_test_cases(6) as per the test case you wish to run before you run swe_test_cases.py
2. This would generate the following files:
    2.1 Slope_test_6.ic (In case you ran test case 6) [Generated by swe_test_cases.py]
    2.2 settings_sim.inp [Generated by swe_test_cases.py]
    2.3 settings_num.inp [Generated by swe_test_cases.py]
    2.4 eta.dat [Generated by SWE1D_HLLC.exe]
    2.5 h.dat [Generated by SWE1D_HLLC.exe]
    2.6 q.dat [Generated by SWE1D_HLLC.exe]
3. Now to view the results
    3.1 Open Slope_test_6.ic (In case you ran test case 6) and delete the header and footer
    3.2 Run runs/view_results.py
